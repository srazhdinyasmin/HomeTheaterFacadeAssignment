
# Home Theater Facade Pattern

## Assignment
Assignment #4 — Facade Pattern

## Description
This Java project demonstrates the Facade
structural design pattern using a home theater
system.

The HomeTheaterFacade provides a simple
interface for controlling multiple devices.

## Design Pattern
Facade Pattern (Structural)

## Subsystem Classes
- Amplifier
- DvdPlayer
- Projector
- Screen
- Lights
- PopcornPopper

## Facade
HomeTheaterFacade provides two methods:

- watchMovie(String movie)
- endMovie()

## Technologies
- Java 17
- IntelliJ IDEA
- PlantUML

## How to Run
1. Open the project in IntelliJ IDEA.
2. Select JDK 17.
3. Open Main.java.
4. Run the main() method.

## Clean Code Principles
1. Meaningful Names
2. Single Responsibility Principle
3. Encapsulation
4. Proper Error Handling
5. Small and Focused Methods
